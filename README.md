# Desafio: Gerador

Solução desenvolvida por Loester Franco Botelho como parte de um desafio técnico, com foco na implementação de novas funcionalidades, refatoração de regras de negócio e validação de integridade de dados.

## Repositório
[https://github.com/LoesterBotelho/challenge](https://github.com/LoesterBotelho/challenge)

## Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET Framework 4.8
- **Testes:** NUnit
- **Processamento de JSON:** Newtonsoft.Json

## Como Instalar e Usar

### Pré-requisitos
Certifique-se de possuir o .NET Framework 4.8 instalado. 
[Download .NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/thank-you/net48-developer-pack-offline-installer)

### Comandos de Configuração e Build
Na raiz do repositório, execute os comandos abaixo para preparar e compilar a solução:

Limpeza do ambiente , Build e Execução:
```bash
dotnet clean
dotnet build
.\ConsoleApp1\bin\Debug\ConsoleApp1.exe test
.\ConsoleApp1\bin\Debug\ConsoleApp1.exe
```
